# Installation / 安装说明

**Official website / 官网：[yinghe.org](https://yinghe.org)** · [All downloads / 下载中心](https://github.com/jo3sheng/yinghe-studio/releases)

## Windows 3.3.3

**64-bit Windows 10/11; .NET Framework 4.8 recommended.**

1. [Download the complete Windows ZIP](https://github.com/jo3sheng/yinghe-studio/releases/download/v3.3.3/YINGHE-Studio-3.3.3-Windows.zip).
2. Extract the **entire** archive to a writable folder.
3. Run **YINGHE-Studio.exe**. Keep the **ffmpeg** folder beside it; FFmpeg, FFprobe and their DLLs are already included.
4. Add a short video and use the five-second preview before exporting your queue.

下载 Windows 完整包后，**完整解压**到可写入文件夹，再运行 **YINGHE-Studio.exe**。请保留同目录 **ffmpeg** 文件夹，无需额外安装 FFmpeg。先用短视频预览，再处理完整队列。

For detailed controls, see the [Windows user guide](USER-GUIDE.md). Hardware encoding depends on a compatible GPU and drivers. Windows may show a publisher or reputation prompt for an unsigned executable; contact support if installation is blocked.

## Mac 1.1.6

**Apple Silicon (M-series), macOS 13 or later. This package is not for Intel Macs.**

1. [Download the complete Mac ZIP](https://github.com/jo3sheng/yinghe-studio/releases/download/v1.1.6-macos/YINGHE-Studio-1.1.6-MAC.zip).
2. Extract the entire archive. It contains **YINGHE Studio.app** and a **Manuals** folder.
3. Keep the app's internal folders intact. FFmpeg and FFprobe are bundled; no separate installation is required.
4. Open the app and follow the PDF guide for your language.

需要 Apple Silicon（M 系列芯片）和 macOS 13 及以上。完整解压后可见 **YINGHE Studio.app** 与 **Manuals** 文件夹；FFmpeg 和 FFprobe 已内置。不要拆开应用内部文件，请按对应语言的 PDF 手册操作。此包不适用于 Intel Mac。

[Download the nine-language PDF manuals separately / 单独下载九语言手册](https://github.com/jo3sheng/yinghe-studio/releases/download/v1.1.6-macos/YINGHE-Studio-1.1.6-Manuals-9-Languages.zip)

Apple Developer ID signing and notarization have not been independently verified for this Mac package. If macOS blocks opening it, contact support for the supported installation path; do not disable system-wide security protections.

## Free, activation and moving computers / 免费版、激活与换机

- **Free:** no registration; ten successful full exports per local day. Preview, failed and cancelled jobs do not count.<br>免费版无需注册，每天成功导出十个；预览、失败和取消不计数。
- **Pro:** purchase at [yinghe.org](https://yinghe.org/buy.php), enter the registration code and activate online. Later processing supports offline use.<br>专业版在官网购买注册码，首次联网激活，之后支持离线处理。
- **New computer:** unbind the old computer online, then activate the same code on the new one. Contact support if the old device is unavailable.<br>换机时先在旧电脑联网解绑，再在新电脑激活；旧电脑损坏或丢失时联系支持。
