# YINGHE Studio

English · [简体中文](README.zh-CN.md)

**A local batch video workspace for Windows and Mac.** Bring your videos together, combine processing settings and export the queue on your own computer. Spend less time repeating the same edits.

## One workspace for a whole batch

- **Batch import and export:** add videos or a folder, manage a queue and apply processing settings across the batch.
- **Crop and reframe:** resize, center-crop, rotate and flip your footage horizontally or vertically.
- **Motion variations:** combine speed changes, interval frame removal and dynamic zoom to vary how a clip looks and moves.
- **Color controls:** refine exposure, brightness, contrast, saturation, highlights, shadows, color temperature and other controls available in your version.
- **Your branding:** place watermarks, adjust their position and opacity, and add image or video picture-in-picture.
- **Intros and outros:** give the batch a consistent opening and ending using video segments or still images.
- **Audio and output:** work with original audio and background music; set output resolution, frame rate and bitrate.
- **Preview before committing:** check a five-second preview, then export the full queue.
- **Local processing:** rendering runs on your computer; your footage does not need to be uploaded for processing. FFmpeg and FFprobe are included in the complete software packages.

See the [Windows guide](docs/USER-GUIDE.md) or the [Mac manuals](https://github.com/jo3sheng/yinghe-studio/releases/download/v1.1.6-macos/YINGHE-Studio-1.1.6-Manuals-9-Languages.zip) for controls supported by your platform and version. Motion variations are editing tools, not a guarantee of duplicate-detection avoidance or copyright clearance.

## Free is useful for everyday work

Download and start without registering, verifying an email or collecting a Free code. Free includes the processing tools and **10 successful full exports per local day**. Previews, failures and cancellations do not use that allowance.

| Feature | Free | Pro |
| --- | --- | --- |
| Video processing tools in your version | Included | Included |
| Five-second preview | Included | Included |
| Successful full exports | 10 per day | No daily cap during the license term |
| Preview, failure or cancellation | Does not count | Does not count toward the Free allowance |
| Registration to start Free | Not required | Purchased code required for Pro activation |
| Price | Free | **US$49 / 365 days** |
| Automatic renewal | None | None; renew manually |
| Active Pro computers | — | One per license |

**Upgrade when the daily allowance gets in your way.** Studio Pro provides 365 days of uncapped exports for **US$49**. It is a one-year license with manual renewal, not a lifetime purchase or an automatically renewing subscription.

Activate online, then process videos offline. To move a license, unbind the old computer online before activating the same code on the new one. Expiry or unbinding restores Free while retaining recorded usage for that day.
